role-member-count-bot is a Discord bot for... just that: setting voicechans counters for bots
I currently do NOT offer this bot for other servers, but you can just host your own

Current version: V0

How to make it work:

Set up a category named "--Server Stats--"
Set under this category voice channels beginning with the names of the roles you want to be tracked
Voice channels will be updated when the corresponding role is assigned to/removed from someone

Due to the Discord limitation of 2 voice channel edits / voice channel / 10min, if needed to edit more often than that... just wait 10min, better stuff will come later
